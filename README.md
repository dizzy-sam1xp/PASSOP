# PASSOP

Password Manager web app built with JavaScript. Features secure local storage, adding, editing and deleting passwords through a clean, user-friendly interface.

## Features

- Save website, username, and password entries from a single form
- View saved passwords in a table, with a show/hide password toggle
- Edit and delete saved entries
- Copy a website, username, or password to the clipboard with one click
- Passwords persist in the browser with localStorage, so they are still there after a reload
- Toast notifications confirm when a password is saved, copied, edited, or deleted

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- React Router
- react-toastify

## How to Run

1. Install dependencies: `npm install`
2. Start the development server: `npm run dev`
3. Open the app in your browser at the local address shown in the terminal.
